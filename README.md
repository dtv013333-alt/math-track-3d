# 🏃 3D 正負數加減法操場賽跑 (Three.js Math Track 3D)

一款使用 **Three.js** 與 **Blender `.glb` 骨骼動作模型** 製作的 3D 校園操場賽跑數學練習遊戲，幫助學生練習正負數加減法！

## ✨ 遊戲特色
- **7 大正負數加減法題型（每圈固定 10 題）**：
  - 負減負：`(-a) - (-b)`
  - 負加負：`(-a) + (-b)`
  - 負加正：`(-a) + b`
  - 負減正：`(-a) - b`
  - 正減負：`a - (-b)`
  - 正加負：`a + (-b)`
  - 小減大（答案為負）：`a - b` (`a < b`)
- **二階段作答機制**：
  - 前兩次直接輸入答案（無選項），答對可獲得 **加速衝刺（Sprint）**，答錯角色會 **跌倒（Fall）**。
  - 若第二次輸入仍錯誤，自動開啟 **四個選項（四選一）** 救援模式，選對即可爬起繼續往前跑。
- **即時天氣變化背景**：
  - 支援自動偵測所在地即時天氣（Open-Meteo API），亦可隨時手動切換 **🌤️ 藍天白雲、☀️ 艷陽高照、☁️ 陰天、🌧️ 下雨天**。
- **角色外觀自訂 & 三位專屬對手**：
  - 可自訂暱稱、性別、膚色、眼色、髮色、9 種髮型、上衣顏色、4 種下身款式與配件。
  - 支援單人對戰三位電腦對手（**柯老師、阿維老師、Lisa**），或透過 **4 碼房號 / QR Code** 與其他載具（平板、手機、電腦）跨裝置聯動同場競速！
